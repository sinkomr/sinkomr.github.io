The farad is another comically large unit; nearly everything interesting happens twelve or more decades below it.

| Scale | Reference point | My encounters |
|-------|-----------------|---------------|
| 10⁻¹⁸ F | Single-electron transistor islands (aF) | |
| 10⁻¹³ F | A transmon qubit's shunt capacitor (~80 fF) | Designed around these |
| 10⁻¹² F | A centimeter of coax (~1 pF/cm) | The parasitic enemy |
| 10⁻⁹ F | Decoupling capacitors (nF) | |
| 10⁻⁶ F | Electrolytics on every board | PCB prototyping stock |
| 10⁻³ F | Camera flash caps; single pulsed power cans (μF to mF at tens of kV) | Marx generator stages |
| 10⁰ F | Supercapacitor cells begin | |
| 3×10³ F | The largest single supercapacitors | |
