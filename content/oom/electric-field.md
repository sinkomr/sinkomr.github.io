The unit behind every insulation decision in pulsed power: it is never the voltage that gets you, it is the voltage per meter.

| Scale | Reference point | My encounters |
|-------|-----------------|---------------|
| 10⁻⁶ V/m | A distant radio station at your antenna | |
| 10² V/m | Earth's fair-weather atmospheric field (~100 V/m) | |
| 10⁵ V/m | Under a thundercloud | |
| 3×10⁶ V/m | Breakdown of air | The number every HV design starts from |
| 10⁷ V/m | Pressurized SF₆ and transformer oil holding on | Insulation engineering |
| 10⁹ V/m | Gate oxides a few nm thick | Routine in every transistor, terrifying anywhere else |
| 5×10¹¹ V/m | The field an electron feels in a hydrogen atom | |
| 1.3×10¹⁸ V/m | The Schwinger limit, where the vacuum itself sparks | |
