Cleanroom classes are the rare standard that is honest about being an order-of-magnitude scale: an ISO class N room allows 10ᴺ particles (0.1 μm or larger) per cubic meter. The count below uses particles 0.5 μm and larger, which is what the old US Federal Standard class numbers count per cubic foot.

|--------------------------|---------|---------------|

| ~10² | ISO 4 (Class 10) | The bunny suit years |
| ~10³ | ISO 5 (Class 100): also a surgical suite | Nanofab bays |
| ~10⁴ | ISO 6 (Class 1,000) | |
| ~10⁵ | ISO 7 (Class 10,000) | Gowning rooms and service chases |
| ~10⁶ | ISO 8 (Class 100,000): clean indoor air | |
| ~10⁷ | Typical city air | |
| ~10⁸ | Wildfire smoke days | The Bay Area's orange-sky season |
| 10⁹ and up | Concrete grinding with no dust control | Why the respirator lives in the shop |
