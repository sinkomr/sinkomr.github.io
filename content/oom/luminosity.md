| 10⁰ lm | An indicator LED | Front panels everywhere |
| 1.3×10¹ lm | A candle | |
| 10³ lm | A 60 W-equivalent LED bulb (800 lm) | The litho bay, but yellow only |
| 10⁴ lm | A cinema projector | |
| 10⁶ lm | Stadium lighting, all in | |
| 4×10¹⁰ lm | The Luxor Sky Beam in Las Vegas | |
| 3.6×10²⁸ lm | The Sun | |
