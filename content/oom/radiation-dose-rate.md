Dose tells you how much; dose rate tells you how it was delivered. The top of this table is the domain of flash X-ray simulators, which deliver a career's worth of occupational limits in tens of nanoseconds.

| Scale | Reference point | My encounters |
|-------|-----------------|---------------|
| 10⁻⁸ rad/s | Natural background (0.3 rad per year) | |
| 10⁻⁷ rad/s | Cruising altitude on an airliner | |
| 10⁻² rad/s | Interventional fluoroscopy, at the skin | |
| 10⁰ rad/s | A radiotherapy beam at the tumor (~2 Gy per minute) | |
| 10² rad/s | Industrial gamma irradiators | |
| 10¹² rad/s | Flash X-ray simulators (10⁵ rad in tens of ns) | Pulsed power's radiation-effects mission |
