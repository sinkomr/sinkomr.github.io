Already a logarithmic unit, so this table is the only one where the left column counts by tens instead of multiplying. Every 10 dB is another order of magnitude in power.

| Level | Reference point | My encounters |
|-------|-----------------|---------------|
| 0 dB | Threshold of hearing | |
| 30 dB | A whisper | |
| 60 dB | Conversation | |
| 70 dB | Cleanroom HVAC, all day long | The soundtrack of nanofab |
| 85 dB | OSHA's 8-hour exposure limit | Where the earmuffs come out |
| 100 dB | A table saw or router | The wood shop |
| 120 dB | A rock concert | |
| 140 dB | A jet at takeoff; pain threshold | |
| ~170 dB | A capacitor bank discharge, up close | You feel a good shot in your chest |
| 194 dB | The loudest possible sound in ambient air | |
| Above 194 dB | No longer sound, now a shock wave | HEDP's preferred regime |
